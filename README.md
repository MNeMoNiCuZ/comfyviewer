# ComfyView

<img width="2273" height="1324" alt="image" src="https://github.com/user-attachments/assets/b96cfff7-e9c9-454f-9c00-fe3ec05ff9d5" />

A browser-based viewer for ComfyUI workflow `.json` files. Drop a workflow onto the
page to see the graph rendered on a canvas — no install, no ComfyUI instance needed.

**Live page: https://mnemonicuz.github.io/comfyviewer/**

## Features

- Drag and drop (or browse to) any ComfyUI workflow JSON
- Pan, zoom, fit, marquee and modifier-key selection
- Move, resize, collapse and rename nodes; group them into comment boxes
- Align, match-size and distribute tools for tidying up a layout
- Node pack report showing which custom node packs a workflow needs, with optional
  on-canvas highlighting and labels
- Save the edited workflow back out as JSON

Everything runs locally in the browser; workflows are never uploaded anywhere.
